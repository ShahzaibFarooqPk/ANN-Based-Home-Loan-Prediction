# 🏠 ANN Based Home Loan Prediction

## 📌 Project Overview

This project uses an **Artificial Neural Network (ANN)** to predict home loan approval outcomes based on applicant information.

The goal is to apply Deep Learning techniques to a loan prediction problem and explore how neural networks can learn patterns from historical loan application data.

## 🎯 Project Objectives

- Build an ANN-based prediction model.
- Understand how neural networks learn from structured data.
- Perform data preprocessing before model training.
- Train and evaluate the model.
- Predict loan approval outcomes for new applicants.

## 🛠️ Technologies & Tools

- **Python** – Programming language
- **NumPy** – Numerical computations
- **Pandas** – Data manipulation and analysis
- **Matplotlib** – Data visualization
- **Scikit-learn** – Data preprocessing and model evaluation
- **Artificial Neural Network (ANN)** – Deep Learning model
- **Jupyter Notebook** – Development environment

## 🧠 Model Overview

An Artificial Neural Network consists of interconnected layers of neurons that learn patterns from input data.

The project uses an ANN approach for a binary prediction task:

- **Input Layer:** Receives applicant information.
- **Hidden Layers:** Learn patterns and relationships in the data.
- **Output Layer:** Produces the prediction.
